# 캡스톤 기말보고서 - 대표 사진/도면/데이터

## 1. 시스템 아키텍처 도식

### 1.1 전체 시스템 구조

```
┌───────────────────────────────────────────────────────────────┐
│                    최종 사용자 (Admin / Respondent)            │
└───────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────────────────────────────────────────────────────┐
│                 프론트엔드 (React + TypeScript)                │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐           │
│ │ 설문 생성/   │ │  응답 수집   │ │   결과       │           │
│ │  편집 페이지 │ │  페이지 +    │ │  분석 페이지 │           │
│ │              │ │  로그 추적   │ │  (평가/통계) │           │
│ └──────────────┘ └──────────────┘ └──────────────┘           │
│                                                                │
│ UI Framework: Tailwind CSS + Lucide Icons                    │
│ 상태 관리: Zustand  |  HTTP: Axios  |  차트: Recharts        │
│ 드래그앤드롭: dnd-kit                                        │
└───────────────────────────────────────────────────────────────┘
                    ↓↑ (REST API / JSON)
┌───────────────────────────────────────────────────────────────┐
│                  백엔드 (FastAPI + Python)                    │
│                                                                │
│  API 계층                                                      │
│  ├─ POST /surveys/                    (설문 생성)            │
│  ├─ GET  /surveys/{survey_id}         (설문 조회)            │
│  ├─ POST /surveys/{survey_id}/responses (응답 제출)          │
│  └─ POST/GET /survey-evaluations/...   (평가 실행/조회)      │
│                                                                │
│  서비스 계층 (핵심 로직)                                      │
│  ┌────────────────────────────────────┐                      │
│  │ 1. Item Quality LLM Service        │  (문항 품질 평가)    │
│  │    → LLM 정성 평가 수행            │                      │
│  ├────────────────────────────────────┤                      │
│  │ 2. Feature Extraction Service      │  (피처 추출)        │
│  │    → 응답 시간, 일관성 등 계산     │                      │
│  ├────────────────────────────────────┤                      │
│  │ 3. Reliability Scoring Service     │  (신뢰도 점수)      │
│  │    → 0~100 신뢰도 점수 산출       │                      │
│  ├────────────────────────────────────┤                      │
│  │ 4. Statistical Evaluation Service  │  (통계 분석)        │
│  │    → Cronbach Alpha, CITC 계산    │                      │
│  ├────────────────────────────────────┤                      │
│  │ 5. Population Feature Service      │  (집단 분석)        │
│  │    → 시간 편차, 이상치 탐지       │                      │
│  └────────────────────────────────────┘                      │
│                                                                │
│  외부 연동                                                    │
│  ├─ OpenAI API (GPT-4): 문항 품질 평가                      │
│  └─ SQLAlchemy ORM: SQLite DB 관리                          │
│                                                                │
│  배포: Uvicorn ASGI Server (Port 8010)                       │
└───────────────────────────────────────────────────────────────┘
                    ↓↑ (Database / External API)
┌───────────────────────────────────────────────────────────────┐
│                 외부 시스템 및 저장소                          │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐           │
│ │  SQLite DB   │ │ OpenAI API   │ │  통계 분석   │           │
│ │  (로컬 저장) │ │ (LLM 호출)   │ │  (결과 계산) │           │
│ └──────────────┘ └──────────────┘ └──────────────┘           │
└───────────────────────────────────────────────────────────────┘
```

## 2. 서비스 화면 캡처 가이드 및 상세 설명

### 2.1 화면 1: 설문 생성/편집 페이지

**캡처 대상 파일**: `frontend/src/pages/SurveyEditorPage.tsx`

**화면 구성 요소**:
- 설문 기본 정보 입력 (제목, 설명, construct 정보)
- 문항 추가 버튼
- 문항 카드 목록 (각 문항별 제목, 보기, 작업 버튼)
- dnd-kit을 이용한 드래그앤드롭으로 문항 순서 변경
- 설문 생성 버튼

**캡처 시점**:
- 빈 설문 생성 화면 (초기 상태)
- 5~10개 문항이 입력된 상태
- 문항 카드의 편집 모달창

**표시할 내용**:
```
┌─────────────────────────────────────────────────────────┐
│  설문 제목: [입력 필드]                                  │
│  설문 설명: [텍스트 에리어]                              │
│  Construct: [입력 필드] (예: 제품 만족도)              │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  ✓ 문항 1: 제품 품질에 만족하십니까?                    │
│    - 매우 불만족 / 불만족 / 보통 / 만족 / 매우 만족   │
│    [수정] [삭제] [☰ 드래그로 순서 변경]                │
│                                                          │
│  ✓ 문항 2: 배송 속도가 적절했습니까?                    │
│    - 매우 느림 / 느림 / 보통 / 빠름 / 매우 빠름        │
│    [수정] [삭제] [☰ 드래그로 순서 변경]                │
│                                                          │
│  [+ 문항 추가]     [< 취소]  [생성]                     │
└─────────────────────────────────────────────────────────┘
```

### 3.1 응답 신뢰도 점수 분포 그래프

```

분포도:
100 |
 90 |        ████
 80 |      ████████████
 70 |    ██████████████████
 60 |  ██████████████████████  ← 신뢰도 임계값 (60점)
 50 |  ██
 40 |  ██
 30 |  ██
 20 |
 10 |
  0 |_____|_____|_____|_____|_____|
      0   20   40   60   80   100

통계:
- 평균: 82.1점
- 중앙값: 84.0점
- 표준편차: 11.3점
- 최소: 32점 (필터링 제외됨)

✓ 90점 이상: 13명 (30.2%) - 신뢰도 매우 높음

✗ 60점 미만: 5명 (11.6%) - 신뢰도 낮음 (분석 제외)
```

### 3.2 문항별 CITC 비교표

```
문항별 Item-Total Correlation (CITC) 분석

┌─────────────────────────────────────────────────────────┐
│ 문항 │ 내용            │ CITC  │ 해석          │ 권고   │
├─────────────────────────────────────────────────────────┤
```
